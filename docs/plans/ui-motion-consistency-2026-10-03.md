# UI 动效一致性

状态：首轮实施完成；人工验收中，后续反馈按实际问题修正。
日期：2026-10-03

## 目标与已确认规则

首轮改善当前高频交互的进出场与布局过渡，保留业务、路由、焦点和滚动语义。
不引入依赖，不修改既有审查修复，不重写全部浮层或建立动画管理器。
默认小幅位移和透明度变化，不使用夸张弹跳，不让筛选与翻页触发整页动画。
背景图和主题色揭示保留原有慢节奏，不套用高频交互的短时长。
追加确认：搜索 token 增删需要布局过渡；建议与筛选共用容器，内容切换不重播容器入场。
建议/筛选自然高度变化与空搜索发现区收展接入高度动画，不缩放内容文字。
页面左右推拉已由哥哥取消；保留短促、轻微的透明度过渡。
本轮不启动纯视觉浏览器验收，整体观感与动画手感由哥哥确认。

## 实施前事实

- 已安装 Motion，shared/ui/animation 已有 Transition 和 variants。
- Select 已有 AnimatePresence；ContextMenu 关闭即卸载，没有退场。
- ThreadPreviewOverlay 使用 CSS 位移/透明度，关闭靠固定 300ms 延时。
- RootLayout 长期保留主滚动区和 Outlet；同路径查询参数变化不应重建页面状态。
- View Transition 的现有主题揭示和 About 页面 wipe 共用长时序。
- AnimatedPagination 已有 layout，DrawSettingsPanel 已有高度展开。
- 书单表单与快捷收藏有明确草稿身份，不允许因动画改变它们的恢复规则。

## 最小设计

参数归属现有 variants，MotionConfig 只负责全局 reduced-motion 默认；
CSS 动画与原生 View Transition 仍单独尊重系统减少动态效果偏好。
浮层退场必须立即停止交互，但节点可为视觉退场短暂保留。
帖子预览由实际动画完成触发关闭，不用与动画时长重复的定时器。
页面仅对主内容透明度做短过渡，固定栏和滚动容器身份不变；
不保留上一业务页面的副作用，不用 pathname key 强制重挂载 Outlet。

   使用现成 layout 能力，不测量全部列表，不动画化固定定位祖先。

## 验证与停止条件

主要证据为现有 ContextMenu、Select、ThreadPreviewOverlay、书单组件与 RootLayout 定向测试；
新增逻辑只补快速开关、退场不交互、pathname 与 query 区分、减少动态效果的高价值用例。
跨模块 props 与公共动效配置补前端类型检查；不默认执行全仓 lint、测试或 build。
若动画需要改变持久化、权限、数据请求或导航语义，暂停并说明；不自行扩大范围。

## 实际结果与验证

- 复用既有 Motion 和 Transition，常规动效为 120–200ms；未新增依赖。
- ContextMenu、Select、帖子预览、书单表单及快捷收藏已接入首轮动效；
  退场立即隐藏交互语义，快速重开建立新草稿。Select 的 portal 随父面板退场关闭。
- 搜索 token 使用位置布局过渡；删除前项不再使后续 token 因索引 key 改变而重新挂载。
- 建议/筛选重播外壳动画的原因是内嵌建议仍独立监听外部 mousedown；
  内嵌模式交由 TopBar 统一关闭，退场建议移除键盘监听。
- AnimatedHeight 观察自然内容高度，支持异步内容及切换内容的高度变化；
  退场收至零高度，动画结束恢复溢出显示，避免日期菜单被裁切。
- 哥哥反馈发现区收展按钮无法点击：新增容器与旧负下边距造成透明区域覆盖按钮。
  已删除按钮负下边距，将内容上间距由 40px 调为 12px，展开时总间距保持一致。
- 页面左右推拉已撤销，没有路由器导航包装；保留 pathname 变化时轻微淡入。
  主题圆形揭示 3.6 秒、背景 wipe 2.7 秒保持原节奏。

## 后续覆盖边界

本轮是首轮高频覆盖，不宣称每个业务弹窗已统一。
其他原生 dialog、图片/卡片到详情的跨容器共享元素动画，需要逐入口核对来源几何、
顶层模态、焦点返回和快速导航；不为“全站动画”机械给每个节点加 layout。
